# 3–5 分钟现场动线

日期：2026-10-17。最稳组合：**文字面试 / 摸鱼艺术家 / 摸鱼前辈 / 四题 / 本地演示**。先打开 `http://localhost:8000`；手机无 HTTPS 时仅演示文字。

1. **0:00–0:30**：首页：“这是校园娱乐面试游戏，十个离谱岗位、五位面试官。今天我应聘摸鱼艺术家。”选岗位和摸鱼前辈；明确勾选本地演示。对观众说“当前是本地题库，真实 API 不可用也能演示完整流程”。
2. **0:30–2:00**：先点“让我想想”，展示题数未变。四次分别输入：“先用脚本做完重复表格”“如果出错，我会抽查并修正”“和队友一起确认完成清单”“我会先沟通，再安排休息”。面试官有反应和后续问题；不要把本地模板称作真实模型追问。
3. **2:00–2:45**：结果页展示五维、批示、录用章和编号，展开规则依据。“这是娱乐分，眼神坚定度没有测眼神。”点“导出 PNG”，实际下载或在手机长按图片保存。
4. **2:45–3:30**：返回大厅进反转模式，选摸鱼艺术家。问“为什么想来做这个岗位？”再点“淘汰小欧”，展示体面退场。可以另开一局展示录取反应。
5. **3:30–4:30，可选**：进视频面试，用已准备的电脑 localhost 或可信手机 HTTPS。先讲“这是角色图动画和回合制交互”，再主动授权。没有真实 API 时只展示镜头开关、静音、打字、挂断出单；不暗示已发生语音识别或合成。

真实模型展示只在 `docs/验收记录.md` 对应项已经补充证据后使用：取消本地演示开关，先做一次短局确认额度、延迟和声音。网络不稳就退出后重新开一局并勾选本地演示，向观众明确说“现在切换本地题库”。单轮自动降级时照读页面提示，不遮掩。

开场前：确认后端仍运行、网页能恢复；不要现场升级套餐或临时换 Key；不要投屏 `.env`；用虚构答案，不展示私人背景物品。摄像头拒绝时直接继续打字。应用完全失联时说“服务端暂时失联，先恢复连接”，不可称全离线可用。
